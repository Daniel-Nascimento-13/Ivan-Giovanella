# Projeto "Ivan Giovanella — Consultor Unimed"

Este repositório reúne uma **landing page** voltada para a divulgação dos serviços de **Ivan Giovanella**, consultor especialista em **planos de saúde Unimed** para a região dos **Vales do Taquari e Rio Pardo (RS)**.

O projeto foi criado com o objetivo de **aumentar a conversão**, transformar acessos em **leads qualificados** e potencializar o **fechamento de contratos** de planos de saúde para pessoas físicas e empresas.

A landing page foi desenvolvida para conectar o cliente diretamente ao atendimento, oferecendo uma experiência **cinematográfica, fluida e envolvente**, além de apresentar os planos de forma estratégica, com foco em **gerar desejo**, **facilitar a tomada de decisão** e conduzir o usuário até o contato com **informações pré-estruturadas**, sendo um projeto **ativo e em uso real**.

O site é destinado a **pessoas físicas, MEIs, pequenas e médias empresas** que buscam contratar um plano de saúde Unimed, permitindo conhecer os planos disponíveis, entender os diferenciais do atendimento e realizar o contato de forma simples, sendo direcionados ao **WhatsApp**, onde o atendimento é finalizado de forma **personalizada e consultiva**.
